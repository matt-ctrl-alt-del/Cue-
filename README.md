<h3> Controls: </h3>
W - Move up,
A - Move left,
S - Move down,
D - Move right.

<h3> Context: </h3>
A game I made as a submission to The Very Serious Juniper Dev Game Jam 2026 & Hack Club Jame Gam.

<h3> Tools: </h3>
I used Godot and Gdscript, for the art I used Aseprite/Libresprite. The sound is not made by me, I got it on the internet.

<h3> AI Disclosure: </h3>
No AI was used in writing the code or making the art.

<h3> Acknowledgments: </h3>
This game is a project for #jame-gam @Hack Club and was submitted to The Very Serious Juniper Dev Game Jam 2026
